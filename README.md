# Cognitive Food Recommendation & Nutrition Analysis

## Features
- User profile input
- Educational BMR/TDEE calorie estimation
- Vegetarian food filtering
- Nutrition analysis
- Cognitive recommendation scoring
- Daily sample meal plan
- Nutrition charts
- Preference-learning simulation

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important
This is an academic prototype. Nutrition values are approximate and the calorie calculation is an educational estimate, not medical or individualized dietary advice.
